# Вариант 2

Решить задачу о рюкзаке с применением генетического алгоритма, с учетом следующих требований:

Придумать условия задачи с количеством предметов не менее 8.
Численность популяции не менее 6 особей, в скрещивании участвует 1/3 популяции.
Для скрещивания выбираются сильнейшие особи, скрещивание – двухточечное.
До выполнения алгоритма сформулировать стратегию применения оператора мутации и правила формирования нового поколения на основе новых особей и особей из предыдущего поколения.
Сформировать не менее 3 поколений, не считая первоначального.

## Условие задачи

|            | A | B | C | D | E | F | G | H |
| ---------- | - | - | - | - | - | - | - | - |
| вес        | 4 | 8 | 10 | 6 | 2 | 2 | 4 | 8 |
| стоимость  | 2 | 8 | 2 | 6 | 4 | 6 | 2 | 1 |

Вместимость рюкзака: 25

## Правило мутации

Если особь является нежизнеспособной применяем к ней оператор мутации 2 раза

## Правило формирования нового поколения

В новое поколение идут особи, получившиеся после скрещивания, а так же 2/3 сильнейших особей предыдущего

## Решение

Первые 6 особей:

 **x1 - 1  0  0  1  0  1  1  1 (общая стоимость = 17)**
 
 x2 - 0  1  1  1  0  0  0  0 (общая стоимость = 16)
 
 x3 - 0  0  1  1  0  0  0  0 (общая стоимость = 8)
 
 x4 - 1  0  0  0  1  1  1  1 (общая стоимость = 15)
 
 **x5 - 0  1  0  1  0  1  0  1 (общая стоимость = 21)**
 
 x6 - 1  1  0  0  1  0  1  0 (общая стоимость = 16)

 В скрещивании учавствует 1/3 всей популяции - это 2 особи. Выбираем для него сильнейших (особи с наивысшей общей стоимостью).
 Это будут особи x1 и x5. Скрещивание 2-хточечние, поэтому хромосому каждой особи делим на 3 части (делим 2-мя точками).

 x1 - 1  |  0  0  1  0  1  1  |  1

 x5 - 0  |  1  0  1  0  1  0  |  1

 В хромосомы одного потомка пойдут 1-я и 3-я части x1 и 2-я часть x5, а во второго 1-я и 3-я части x5 и 2-я x1.

 x7 - 1  |  1  0  1  0  1  0  |  1

 x8 - 0  |  0  0  1  0  1  1  |  1

 Особь x7 нежизнеспособна, так как в ней превышается вместимость, поэтому она мутирует.

 x7 - 1  1  0  1  0  1  0  1  ->  x7 - 1  1  0  1  **1**  1  0  1  -> x7 - 1  1  0  1  1  1  0  **0**

 Итог: x7 - 1  1  0  1  1  1  0  0

 1-е поколение:

 **x1 - 1  0  0  1  0  1  1  1 (общая стоимость = 17)**
 
 x2 - 0  1  1  1  0  0  0  0 (общая стоимость = 16)

 **x5 - 0  1  0  1  0  1  0  1 (общая стоимость = 21)**
 
 x6 - 1  1  0  0  1  0  1  0 (общая стоимость = 16) 

 x7 - 1  1  0  1  1  1  0  0 (общая стоимость = 16) 

 x8 - 0  0  0  1  0  1  1  1 (общая стоимость = 15) 

 Скрещивание:

 x1 - 1  |  0  0  1  0  1  1  |  1

 x5 - 0  |  1  0  1  0  1  0  |  1

 x9 - 1  |  1  0  1  0  1  0  |  1

 x10 - 0  |  0  0  1  0  1  1  |  1

 
 Особь x9 нежизнеспособна, так как в ней превышается вместимость, поэтому она мутирует.

 x9 - 1  1  0  1  0  1  0  1  ->  x9 - 1  **0**  0  1  0  1  0  1  -> x9 - 1  0  0  1  **1**  1  0  1

 Итог: x9 - 1  0  0  1  1  1  0  1

 2-е поколение:

 x1 - 1  0  0  1  0  1  1  1 (общая стоимость = 17)
 
 x2 - 0  1  1  1  0  0  0  0 (общая стоимость = 16)

 **x5 - 0  1  0  1  0  1  0  1 (общая стоимость = 21)**
 
 x6 - 1  1  0  0  1  0  1  0 (общая стоимость = 16) 

 **x9 - 1  0  0  1  1  1  0  1 (общая стоимость = 19)**

 x10 - 0  0  0  1  0  1  1  1 (общая стоимость = 15) 

 Скрещивание:

 x5 - 0  |  1  0  1  0  1  0  |  1

 x9 - 1  |  0  0  1  1  1  0  |  1

 x11 - 0  |  0  0  1  1  1  0  |  1

 x12 - 1  |  1  0  1  0  1  0 |  1
 
 Особь x12 нежизнеспособна, так как в ней превышается вместимость, поэтому она мутирует.

 x12 - 1  1  0  1  0  1  0  1  ->  x12 - 1  1  0  1  **1**  1  0  1  -> x12 - 1  1  0  1  1  1  0  **0**

 Итог: x12 - 1  1  0  1  1  1  0  0

 3-е поколение:

 x1 - 1  0  0  1  0  1  1  1 (общая стоимость = 17)
 
 x2 - 0  1  1  1  0  0  0  0 (общая стоимость = 16)

 x5 - 0  1  0  1  0  1  0  1 (общая стоимость = 21)

 x9 - 1  0  0  1  1  1  0  1 (общая стоимость = 19)

 x11 - 0  0  0  1  1  1  0  1 (общая стоимость = 17)

 **x12 - 1  1  0  1  1  1  0  0 (общая стоимость = 26)**

 Для ответа берём сильнейшую особь последнего поколения. В нашем случае это x12.

 ## Ответ:

 Стоимость = 26, предметы: A, B, D, E, F.

 ## Ответ программы при аналогичных данных:

 Максимальная стоимость: 26, индексы предметов: [0, 1, 3, 4, 5]
